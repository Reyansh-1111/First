# First

This repository is a simple Python example project created for learning and testing basic script execution.

## Overview

This project demonstrates how to run a minimal Python script that prints a message to the console.

## Usage

Run the script with:

```bash
python hello.py
```

## Example Output

```python
print("Hello")
```

This will output:

```text
Hello
```

## Notes

This is a beginner-friendly example and can be used as a starting point for learning Python basics.
